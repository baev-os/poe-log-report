Choose a day to view events in time order. The bar shows the number of
selected events for that day. All dates use the analysis time zone.

This timeline includes area entries, character level-up and death messages,
displayed death counts, log openings and unexpected disconnections.
It is a selection of confirmed message types. Chat, game dialogue and
other technical lines are not included in this event list.

Each record supplies its own time. Sorting accounts for the UTC offset;
equal timestamps retain source line order. Lines without their own valid
timestamp are not assigned a neighbouring event's time.
Days without dated records are omitted.

Log opening does not prove the start of a game session. Gaps between
messages do not measure playtime or inactivity. Character messages may
refer to other players; character ownership is not inferred here.
A death counter is a displayed cumulative value, not a new death.
