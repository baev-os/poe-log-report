# Notices

Full third-party licenses are preserved unchanged. Native.txt/Native.json
describe Linux libraries; TclTk.txt/TclTk.json contain verified Tcl/Tk source notices;
Exile-UI.txt contains the license for the mercenary greeting list.
WindowsNative.txt/WindowsNative.json bind copied Windows DLLs to exact reviewed
CPython binary bytes, component versions, upstream sources, and original notices.
[Microsoft runtime conditions](WINDOWS_RUNTIME.md) remain separate from the
project's MIT license. Unknown or changed DLLs require a new catalogue review.

The builder adds licenses for installed packages, Python, Bootstrap, and DejaVu,
verifies sources and hashes, and includes the bundle in the standalone distribution.
[Game material terms](GAME_DATA.md).
