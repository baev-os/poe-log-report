# Output

The GUI creates `report/` and an `index.html` entry page. The basic and extended sites
are saved in `report/basic/public/` and `report/extended/public/`; PDFs are saved
in `report/pdf/basic/` and `report/pdf/extended/`.

The basic report contains charts, characters, maps, a calendar, and conversations.
The extended report includes the basic section and detailed pages. Select a language
before generation; original messages are preserved. HTML and PDF share the same
measurements. Reports may contain personal data from the selected logs.
